### 🌐 Web & product

**[portfolio-2026](https://github.com/JScoder4005/portfolio-2026)** · personal site
A Next.js 16 portfolio built around a custom Three.js aurora shader and GSAP timelines. Server Components for the content layer, client islands for the motion. Tailwind for the layout, framer-motion for the micro-interactions. Shipped as a learning project for the new Cache Components model in Next 16.
`Next.js 16` · `TypeScript` · `Three.js` · `GSAP` · `Tailwind` · `framer-motion`

**[mern-prep-dashboard](https://github.com/JScoder4005/mern-prep-dashboard) — PrepDeck**
Next.js 16 dashboard that renders a MERN interview-prep vault (markdown + MDX) with search, tagging, and progress tracking. Fully RSC, Dockerized, CI through GitHub Actions. Started as my own prep notes, became a public dashboard.
`Next.js 16` · `RSC` · `Tailwind` · `Docker` · `GitHub Actions`

### 🖥️ Linux & systems

**[cmf-control](https://github.com/JScoder4005/cmf-control)**
Open-source Linux tray app for the CMF Buds Pro 2 — the official app is Android-only. Talks to the earbuds over BLE, exposes ANC modes, EQ, battery and firmware info through a PyQt6 system-tray UI. Reverse-engineered the vendor GATT protocol from Android packet captures. Daily-drives on my Ubuntu desktop.
`Python` · `PyQt6` · `BLE / GATT` · `dbus`
